# Зоны контроля в бою (#63)

Состояние: **перенесено и сверено** — `h4_rules::battle::zone_of_control` (стенд
`tools/testbench/zone_of_control.py`: `172000` с настоящим кэшем `48b350`/`48b090` и `172210`
целиком, 300 полей: списки угроз 22 585 клеток и 10 481 маска, из них 2065 ненулевых).
Направление взгляда существа — вход (#189).

## Угроза: какие клетки существо держит

Исходник `threat_footprint.cpp`. У каждой клетки поля (запись 0x1c байт) список «угроз» в
`+0x10` (голова `+0x14`, число `+0x18`) — существа, держащие клетку; `+4` — другой список
(объекты для блокировки, `183a10`).

- `172000(X)` добавляет X во все клетки его маски угрозы (`1835f0`: в конец списка, если ещё
  нет). Угол маски — `(X.позиция >> 4) − (W − размер) / 2` (это досягаемость); клетки вне поля
  пропускаются. `172110` (`on_removed`) убирает тем же обходом (`1836d0`).
- `1efd60(X)` — маска: `W = размер + 2r`, `r` = 6 с `long_weapon` 0x25, иначе 2; дуга 200°,
  с `hydra_strike` 0x1d — 360° (способность 0 спрашивается, ответ не используется);
  направление взгляда `X+0x6c`. Кэш `48b350` (`std::map` по (W, направление, дуга)).
- `48b090(W, направление f, дуга)`: клетка `(i, j)` квадрата W×W — смещение от центра вдвое
  `(a, b) = (1 − W + 2i, 1 − W + 2j)`; в маске, если `a² + b² ≤ W²` и (дуга ≥ 360 или разница
  угла `11ed40(a, b)` с `45·f` (`11ed80`) не больше половины дуги: исключается при
  `дуга < 2·разница`). Заодно пишется направление клетки (`11edb0`, `((2·угол + 45) / 90) & 7`;
  в зонах не используется).

## Штраф: `172210(существо C, угол P, out[8])`

Метод поля; результат читает поиск пути (`20d200`: шаг в направлении d из клетки с флагом
`out[d]` дороже на `движение >> 2`).

1. Способность 0x20 `ignore_zones_of_control` у C — всё 0.
2. «Летун» C — нет эффекта 7 и (способность 0x19 `flying` или эффект 0x2e).
3. Для каждой клетки футпринта C (обычная круглая маска размера C, `f0f0` → `1fc590`) в углу P
   (границы не проверяются) — каждое X из списка угроз клетки: другая сторона (`+0x98` слот
   `+0x74`), число не 0 (слот `+0x40`), и, если C летун, X тоже летун. Первое такое X
   включает все 8 направлений; для каждого — направление от центра X (`позиция + 8·размер`)
   к центру C (`16P + 8·размер C`) (`11ede0`, та же формула, что `51ede0`), и сбрасываются
   `d & 3` и `(d & 3) + 4` — шаги прямо к врагу и от него без штрафа.
4. Если никого — всё 0.
