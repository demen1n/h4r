# Может ли стек ответить на удар (#65)

Проверка ответа — rva `1f23c0`, метод `t_combat_creature` с аргументами (атакующий,
`ranged`, число `n`); слот `+0x10` vftable `t_attackable_object` у `t_combat_creature`
(таблица rva `582450`, рядом с приёмом урона `1f2800`). `this` — подобъект `+0x9b4`.

**Сверено исполнением и портировано**: `h4_rules::battle::retaliation`
(`can_retaliate`, `can_shoot` — наши имена), 4490 векторов `tools/testbench/retaliation.py` →
`crates/h4-rules/tests/retaliation_vectors.tsv`. Функция исполняется целиком,
вместе с проверкой «может стрелять» (`170780`), центрами футпринтов (`f100`, `28c60`), x87-корнем
и `__ftol`. Заглушки — способности и эффекты, размер футпринта, ответ проверки
«может ли эффект подействовать» `1b6120` и счётчик карты угроз `10d200`.

Способности — слот +0x68 vtable по `+0x98`; эффекты (`t_spell`) — слот +8 vtable
виртуальной базы. Имена способностей — `re/enum_creature_ability.tsv`.

Ответа нет, если (в порядке проверок):

1. байт цели `+0xa9` установлен и `n < 2` — вероятно, «уже отвечал в этом раунде»
   (соседний `+0xa8` — «уже ходил», см. `decomp/initiative.md`); смысл `n` не установлен;
2. на цели эффект 0xba и `n <= [цель+0x990]`;
3. на цели эффект 0x9a и `n <= [цель+0x810]`
   (0xba и 0x9a входят в список проверки «недееспособен», rva `1eed50`:
   0x0b, 0xba, 0x9a, 0xb4, 0x15, 0xae);
4. ближний бой (`ranged == false`):
   - у атакующего способность 0x2e `no_retaliation`;
   - досягаемость: 6 со способностью 0x25 `long_weapon`, иначе 2. Если у атакующего
     она больше, чем у цели, считается зазор в клетках (клетка = 16 единиц позиции):
     ```
     центр цели       = (x >> 4 << 4) + 8·размер   (по клетке)
     центр атакующего =  x + 8·размер              (по точной позиции)
     d = trunc(sqrt(dx² + dy²) + 0.5)              (32-битные квадраты, x87)
     зазор = (d − 8·размер_цели − 8·размер_атакующего + 8) >> 4
     ```
     зазор больше досягаемости цели — ответа нет (длинное оружие бьёт издалека);
   - на атакующем эффект 0x24, эффект 0x25 может подействовать на цель (`1b6120`),
     и у цели нет способности 0x10 `death_protection`;
   - у атакующего способность 0x30 `panic`, эффект 0x6b может подействовать на цель,
     и у цели нет способности 0x10;
5. дальний бой (`ranged == true`): ответ есть ровно тогда, когда
   цель может стрелять (`170780`, метод `t_battlefield`): способность `ranged` (0x33), нет
   эффекта 0x2f, выстрелы > 0 и нулевой счётчик цели в карте угроз поля
   (`bf+0xe8`, `10d200`; похоже, число соседних врагов — не проверено).

Иначе ответ возможен.

## Что выяснено дальше

Порядок удара, кто ставит и снимает `+0xa9` и откуда берётся `n` — в
`decomp/melee_attack.md`. Коротко: начало ближней атаки (`16ede0`) вызывает проверку
ответа с (атакующий, false, 1) до удара; без первого удара ответ идёт одновременно с
ударом; флаг ставит пометка «ответил» (`1f6b20`), снимается он через раунд в той же
точке очереди инициативы (`1f6b60`, `1ecfb0`).
