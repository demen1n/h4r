# Карты `.h4c`

Источник: декомпилят нашего `heroes4.exe` (rva ниже; сырой вывод — `h4c_header.c`, `h4c_map_tiles.c`), проверка на всех 106 картах установки (`cargo run --release --example check_maps`). Читатель — `crates/h4-formats/src/map.rs`.

## Файл

```
"H4CAMPAIGN"  u32 0x16 (версия файла)  u8 0 (не мультисценарий)  gzip-поток
```

У всех 106 карт gzip начинается со смещения 15. Мультисценарные файлы (кампании, `t_multi_scenario_campaign_file_header`, список `t_map_info`) не разбирались. `t_single_scenario_campaign_file_header::read` (rva `1a9120`) открывает поток через `t_inflate_filter` и читает только заголовок карты. Потом `t_adventure_map::read_from_map` (rva `d15c0`, в мапе имени нет, найдено по вызову читателя заголовка) читает тот же поток с начала целиком.

## Порядок в потоке (`read_from_map`)

1. Заголовок карты (rva `37a320`, `read(streambuf, t_map_header&, progress)` из `map_header.obj`).
2. `FUN_004cf730` (видимо, игроки по заголовку, поток не читает?), события: timed (`cfd80`), `cffe0` (triggerable?), `d0240` (continuous?), placed (`d04f0`).
3. 12 раз `FUN_007c65f0(i, stream, version)` — что это, неизвестно.
4. `d0820`, `d0a40`, `d0c10` (obelisk / player data / allowed artifacts — порядок по мапу, не проверено), с версии 18 `f12d0`/`858150`, затем `d0f00`, `d1370`, с версии 22 два `551330`, с версии 23 AI importance maps (artifact + 2× spell).
5. `FUN_004cf010(stream, …, progress, version)` — судя по размеру секции, объекты карты.
6. Тайлы: уровни → ряды → столбцы в пределах ряда (ромб, см. ниже). Один тайл — `FUN_004139d0(stream, tile_version)`.
7. С версии 2 — высоты `read_heights` (rva `cf4b0`): по байту на вершину.

Части 2–5 не разобраны. Начало тайлов `map.rs` сейчас находит с конца: части 6 и 7 по размеру однозначно определяются заголовком и стоят в конце потока. Поэтому ищется смещение, с которого ровно нужное число корректных тайлов кончается ровно там, где начинаются высоты. На всех 106 картах такое смещение одно (после проверки формы поля видимости, см. ниже). Это временное решение: начало тайлов совпадает с концом объектов, и когда объекты будут читаться, его можно будет проверить.

## Ромб тайлов

`t_isometric_map_base_base::base_initialize` (rva `34db60`): карта size×size хранится рядами, ряд r — столбцы `[start, end)`. Верхний и нижний ряды — по 2 тайла, средние — полные (для 76: ряд 0 = 37..39, ряды 37–38 = 0..76, всего 2964 тайла на уровень). На экране этот ромб в изометрии даёт прямоугольник (подтверждено отрисовкой). Вершины (`t_isometric_vertex_map_base::initialize`, `34de80`) — size+1 рядов, каждый охватывает углы соседних рядов тайлов (+1).

## Тайл

Версия формата тайла зависит от версии карты (`FUN_004cad60`): >25 → 4, >18 → 3, ≥8 → 2, 6–7 → 1. В установке только 4.

```
u8 terrain (0..18), u8 subtype (< число подтипов: 2 у 0..8, 1 у 9..18)
u8 road (0..3)
u8 rock_terrain (0..2), u8 rock_transition (bool)    // версия ≥1
u32 visibility (версия 4) | u16 (версия 3: 6 полей по 2 бита → 3 бита, | 0x80000)
u8 n, n × { u8 terrain, u8 subtype, u16 id (9 бит), u8 mask_set (5 бит) }    // terrain transitions
u8 m, m × { u8 road, u16 id (9 бит), u8 mask_set (5 бит) }                   // road transitions
```

Имена полей — из геттеров `t_abstract_tile` / `t_terrain_transition` / `t_road_transition` в мапе (`get_road_type`, `get_rock_terrain_type`, `has_rock_terrain_transition`, `get_visibility`, `get_id`, `get_mask_set`). В памяти тайл упакован в u32: terrain 5 бит, subtype 1, road 2, rock 2, флаг 1, visibility выше.

- Enum земли (таблица rva `5958d8`): water, grass, rough, swamp, volcanic, snow, sand, dirt, subterranean, river, lava, ice, special_all/life/order/death/chaos/nature/combat. river/lava/ice — это реки (`terrain.river.water|lava|ice.*`), special_* — магические земли (`terrain.magic.*`).
- **Переходы сохранены в карте** (их считает редактор): id ≤ 92 (93 маски в наборе, т.е. это индекс маски, а не код), mask_set ≤ 19 (в `transition.Transitions` наборов 15 — соответствие не выяснено).
- visibility: у всех тайлов всех карт биты выше 17 равны ровно 0x80000. На этом построена проверка, которая убирает ложные стартовые смещения у 3 карт. Гипотеза: 6 игроков × 3 бита видимости.
- Типы дорог 1–3 соответствуют dirt/gravel/cobblestone — это гипотеза, с игрой не сверено.

## Проверено

- 106/106 карт: заголовок читается, тайлы и высоты сходятся ровно до конца потока, стартовое смещение единственное.
- Смысл: подземный уровень почти везде subterranean/dirt, имена и описания — осмысленный русский текст, тексты победы и поражения стоят на своих местах, размеры совпадают с ожидаемыми 76/152/228/304.
- Отрисовка в `h4-game` (`H4_MAP=…`): реки, дороги и области земли складываются в цельную карту. С оригиналом попиксельно не сверено.
