# Новый день

Адреса — наш exe (rva). Функции передачи хода (следующий игрок, конец дня, новый день карты) в нашем exe ещё не найдены.

## Армии

Новый день армии (`t_creature_array`, rva `23fd50`, аргумент bool): для каждого непустого слота вызывает его новый день (игрок, флаг, армия, …; слот `+0xcc` vtable). Армия на карте (`t_army`, rva `1210d0`) вызывает её с флагом 1.

Новый день стека (`t_creature_stack`) — rva `250ca0`: временные бонусы стека (вектор по 0x18 байт, `+0x64..+0x68`) теряют день, истёкшие снимаются (их величина вычитается из стата по индексу); затем запас движения `+0x70` = `min(m·11/25 + 1200, 3000) + бонус (+0x24)` — то же, что базовый запас движения (`250db0`, `movement.md`).

Новый день существа (`t_creature`) — rva `23de10`: сначала базовая часть (выше); у существа 0x2f (по enum — leprechaun?) — доход владельцу (`7e40c0`); затем, если у армии нет игрока-владельца и флаг стоит, — **рост нейтрального стека**:

```
weekly = min(count * 256 / 10, traits.weekly_growth (+0x70) * 256)
today  = weekly / 7 + remainder (+0xa4)
count += today >> 8
remainder = today & 0xff
```

То есть десятая часть стека в неделю, но не больше недельного прироста существа, поровну на 7 дней, доли — в 1/256.

## Карта

Новый день карты (метод `t_adventure_map`) — rva `d8c00` (у Swift-ремейка `0x4d8910` в английском exe; рядом новый месяц, rva `d8f40`): счётчик дней карты `+0xec` (с нуля) увеличивается, при `день % 28 == 0` — новый месяц.
