# Мораль в бою (#61)

Источник — русский exe 3.0 (Бука); адреса — RVA. Порт: `h4-rules/src/battle/morale.rs`
и методы `BattleState` (`side_strength`, `update_loss_penalties`, `army_morale`, `morale`).
Сверка: `tools/testbench/morale.py` → `h4-rules/tests/morale_vectors.tsv` (2928 векторов).

Как мораль влияет на очерёдность (бросок `% 10`, «плохая/хорошая», приоритет ±1000) —
`decomp/initiative.md`. Здесь — откуда берётся само число.

## Геттер `1efbd0`

По порядку:
1. эффект `0x91` «скорбь» (sorrow) → −10;
2. эффект `0x94` «духовный пыл» (spiritual fervor) → 10;
3. способность `0x2a` mechanical или `0x4d` undead → 0;
4. иначе `+0xae8 + +0xaec`, +5 под эффектом `0x67` «мораль», −10 под `0x19` «отчаяние»
   (despair), предел −10..10.

`1efb90` (без заклинаний): нежить/механизмы 0, иначе `+0xae8 + +0xaec` без предела.
Эффекты — виртуальный `+8` виртуальной базы `+0x9c`, способности — `+0x68` статов `+0x98`.

## База `+0xae8`

Ставится в конструкторе боевого существа (`1eb050`, `1eb418..1eb43e`): виртуальный `+0x74`
участника армии, плюс, если армия передана, мораль армии `23fe40` для его мировоззрения.

- `+0x74` у стека и у героя — `251500`: поле `+0x14` (бонус, который участник носит с
  карты; откуда — #213) и +5 под эффектом `0x67` на участнике (`+0xb8`, битовый набор `+0x84`).
- Вне боя мораль стека в окне армии — `251490`: то же плюс наибольший бонус героев армии
  (`+0xf0` для каждого героя, у существа это `23d4a0`: нежить и механизмы — 0); в бою
  бонусы героев идут через влияния (ниже).

### Мораль армии `23fe40`

Для 7 слотов армии: у кого численность (`+8`, виртуальный `+0x40`) не 0 — отметить его
мировоззрение (`+8`, `+4`) и запомнить, есть ли нежить (виртуальный `+0xb4`: у существа
`23d9f0` — бит 13 слова `+0xd4` записи свойств, то есть способность `0x4d` undead; у героя
`f140` — никогда). Затем `1 + Σ` по отмеченным мировоззрениям 0..5 таблицы VA `0xa648d8`
`[0, −1, −2, −5]` по отношению `11ecd0(своё, другое)`:

- 0 — то же; 2 — одно из них might (5); 1 — соседи по кругу life–order–death–chaos–nature
  (`(a − b + 5) % 5` равно 1 или 4); 3 — противоположные.

Нежить в армии и своё мировоззрение не death (2) — ещё −2. Своё мировоззрение тоже
отмечено, но даёт 0.

Численность у героя — 1 (`67a50`), мировоззрение — поле героя `+0xa0` части `+8`
(у нас — из класса). В `BattleState` армия берётся как пришла (`initial_count`).

## Потери стороны: `1761e0`, `176250`

`16f2c0` — начало раунда: если `battlefield+0x28` (активный участник) пуст — первый раунд,
`initialize_morale` (`1761e0`): броски морали всех (`1f2c30`) и сумма силы участников по
сторонам в `battlefield+0x454`, штрафы `+0x40c` обнуляются; иначе `176250`:

```
сейчас[s] = Σ сила участников стороны s
доля[s] = сейчас < было ? (сейчас − было)·10 / было : 0     (деление к нулю)
штраф[s] = min(доля[s] − доля[другой], 0)
```

Разница со старым штрафом прибавляется к `+0xae8` всех участников стороны (поле байта
`+0xa0`), новый штраф запоминается. Значит, база `+0xae8` = собственная мораль + мораль
армии + текущий штраф стороны — так и считает `BattleState::morale`.

### Сила участника `1f5350`

Виртуальный `+0x2c` части `+0x9b4`, аргументы (флаг, исключённый эффект); мораль передаёт
(0, −1). HP одного (виртуальный `+0x30` участника армии), по очереди +¼ (`(hp + 2) >> 2`)
за «силу великана» `0x33`, «прилив здоровья» `0x39`, «молитву» `0x72`, ×2 за «силу дракона»
`0x21`; × численность (`+0xb0`) − раны (`+4` виртуальной базы); плюс запас «небесной брони»
`0x10` (`+0x198`) и «выпивания жизни» `0x44` (`+0x408`), если эффект есть. Ветка флага
(воскрешаемые, `+0x350`) мораль не трогает.

Герои: HP героя в бою не восстановлены (#71), `BattleState::side_strength` их не считает.

## Влияния `+0xaec`

`1f0ea0` пересчитывает «влияния» (`t_creature_influence`): по списку `+0xa60` берёт
наибольшие значения полей влияний (мораль `+0x60` → `+0xaec`, удача, движение `+0xaf8` и
другие) и прибавляет бонусы своего героя (`7258b0`, `725890`). Не перенесено (#212) — вход
`MoraleSources::influence`.

## Сверка

`tools/testbench/morale.py` исполняет целиком: `23fe40` + `11ecd0` на настоящих vtable
`t_creature` и `t_hero` (численность, мировоззрение через записи свойств `255370`, флаг
нежити), `1efbd0`/`1efb90`, `1f5350` с аргументами (0, −1), `176250` по списку существ поля.
Подменены: записи свойств (только мировоззрение и бит нежити, флаг «загружено»),
способности и эффекты — таблицы байтов, HP одного и (в `176250`) сила каждого — готовые
значения. 708 армий, 920 геттеров, 800 сил, 500 обновлений штрафа — 0 расхождений.

Не сверено исполнением: подключение в `BattleState` (порядок `16f2c0` и `1eb050` — по
дизассемблеру), `initialize_morale` (сумма тривиальна, броски — `decomp/initiative.md`).
