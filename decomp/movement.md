# Движение армий по карте приключений

Имена — из отладочного мапа (`creature_stack.obj`, `creature.obj`, `creature_array.obj`, `hero.obj`, `adventure_path_finder.obj`); адреса — наш exe (rva, VA = rva + 0x400000). Большая часть декомпилята здесь пустая (Ghidra выкидывает циклы по 7 слотам), всё ниже прочитано по дизассемблеру.

## Стоимость земли

`get_terrain_cost(t_terrain_type)` — rva `250e90` (и две его копии `250ef0`, `250f50`, это заинлайненные `get_army_move_cost`/`get_move_cost` с той же таблицей). Таблица на 19 типов, по умолчанию 100, поверх — пары (тип, стоимость) из VA `0x985378`:

| тип | стоимость |
|---|---|
| 2 rough | 125 |
| 3 swamp | 200 |
| 4 volcanic | 125 |
| 5 snow | 175 |
| 6 sand | 150 |
| 9 river | 150 |
| 11 ice river | 150 |
| 15, 16, 18 (магические) | 125 |

Остальное (water, grass, dirt, subterranean, lava river, 12–14, 17) — 100.

## Стоимость шага для армии

`t_creature::get_move_cost(terrain)` — rva `23d520` (в мапе переноса подписано как `std::copy`, это ошибка; слот 30 главной vtable `t_creature`, VA `0x98469c`): стоимость земли; если земля родная (`is_native_terrain`) и стоимость > 100, то `max(стоимость − 50, 100)`.

`t_creature::is_native_terrain` — rva `23d9a0`: тип ≥ 9 — нет; иначе да, если у стека есть бонус «родная земля» для этого типа (rva `2535d0`, поле стека по индексу `8 + тип − 1`, у обычных стеков 0 — пока не моделируем), или тип равен родной земле фракции: таблица VA `0x9845e8` по `traits+0x44` — haven 1 (grass), academy 5 (snow), necropolis 4 (volcanic), asylum 3 (swamp), preserve 1 (grass), stronghold 2 (rough).

`get_army_move_cost(terrain)` — что участник даёт всей армии:
- стек (`t_stack_with_backpack`, rva `2536f0`): 100, если `has(0x6c)` (vfunc `+0xb8`; видимо, артефакт или эффект «без штрафов земли»), иначе стоимость земли;
- герой (rva `331ac0`): то же, затем, если > 100 и герой жив: минус скидка «Поиска пути» по мастерству (`hero+0x72c`, таблица VA `0x98915c`: нет 0, базовый 25, продвинутый 50, эксперт/мастер/гранд 100); если стало < 100, или бонус родной земли (`2535d0`), или `325740(hero, terrain)` (rva) (родная земля героя, не разобрано) — 100.

`t_creature_array::get_move_cost(terrain)` — rva `23f960`:
1. максимум `get_move_cost` по живым участникам, у которых vfunc `+8:+0x14` возвращает 0 — то есть по существам (у героя этот слот, rva `329f70`, возвращает указатель на самого героя); если таких нет — стоимость земли;
2. затем минимум с `get_army_move_cost` каждого живого участника (и героев, и существ).

## Очки движения

`t_creature_stack::get_raw_adventure_movement` — rva `250db0`: `min(m·11/25 + 1200, 3000) + бонус (+0x24)`, где `m` — vfunc `+8:+0x18`: у существа `traits+0x5c · 100` (столбец Move таблицы, rva `23d5b0`), у героя константа 2400 (rva `32a1f0`). Деление целое.

Модификатор (`t_creature_array::get_movement_modifier` rva `2421f0` → `t_creature_stack::get_adventure_movement_modifier` rva `250df0`): `k = bonus / raw + mult` (float). Третий аргумент — число пустых слотов армии; ветка с ним (`bonus/raw + (пустые/raw)·mult`) срабатывает только у героя при `raw < пустые`, то есть никогда.

- `bonus` (`get_move_bonus` rva `242270`) = максимум `get_army_move_bonus(море)` по слотам: существо — 1500 на море, 0 на суше (rva `250da0`); герой — 0 на суше, на море (таблица VA `0x98912c` по `hero+0x730` + артефакты)·15: без навыка 100 → 1500, далее 125/150/200/250/300; на море ещё +1000, если у армии что-то есть (rva `e5cf0`, не разобрано).
- `mult` (`get_move_multiplier` rva `242300`): на море 0.0; на суше максимум из 1.0 и `get_army_move_multiplier` слотов: существо 1.0 (rva `23d420`), герой (таблица VA `0x989144` по `hero+0x72c` + артефакты)·0.01: без навыка, базовый, продвинутый, эксперт 1.0, мастер 1.25, гранд 1.5.

Максимум очков армии (`get_max_movement` rva `241a10`) = минимум по живым слотам `⌊raw·k + 0.5⌋` (`__ftol` усекает). Остаток (`get_movement` rva `241940`) = минимум `⌊left·k + 0.5⌋`, где `left` — float у каждого стека (`+0x70`), в его собственных единицах (полный запас = `raw`). Списание (`change_movement` rva `241870`): каждому живому слоту `left += delta / k`, ниже 0 — 0.

## Поиск пути

`t_adventure_path_finder::search_to` — rva `ff580`. Перед поиском считается стоимость армии на все 19 типов земли (`23f960`) и запас на суше и на море (vfunc `+0x28` армии, 0/1). Стоимость шага в клетку (rva `ffe39`):
- шаг по мосту (флаг в `t_adv_map_point+0xc`) — 75;
- (флаг `[esp+0x20]`, не разобран) — 100;
- иначе стоимость армии для земли клетки (`tile & 0x1f`); если дорога есть и в исходной, и в целевой клетке (`tile & 0xc0`), то по дороге целевой: код 2 (dirt) — 100, 1 и 3 (gravel, cobblestone) — 75;
- диагональный шаг (нечётное направление): `c + c/2` (целое).

Остаток после шага: если `c < остаток` — `остаток − c`, иначе шаг всё равно делается, а дальше путь считается со следующего дня с полным запасом (суша или море). Вместе с обрезанием до 0 в `change_movement` это правило: **пока очки есть, следующий шаг можно сделать всегда; шаг, который стоит не меньше остатка, забирает всё.**

Не разобрано: `check_trigger`, `enter_blocked_tile`, `check_danger` / `find_restrictive_enemy` (зоны монстров), вода и посадка на корабль, порядок обхода соседей и сравнение в очереди (`t_compare_adjusted_move_cost`).
