# Позиции для удара: список углов атаки (#186)

`t_attack_angle_list` — где атакующий может встать, чтобы ударить цель в ближнем бою. Его
предлагает интерфейс игрока (`171dc0`, `173740`: поиск без режима атаки) и берёт ИИ; кэш —
`t_ai_combat_data_cache::get_attack_angles` (`10c1a0`), строит список rva `10c870`.

Состояние: **перенесено и сверено** — `h4_rules::battle::attack_angles` (стенд
`tools/testbench/attack_angles.py`, 400 случаев, `10c870` целиком). Подключено к
`move_command::approach_and_attack` (клетка подхода должна быть в списке) и
`attack_positions_against`. Цель из нескольких частей (стены, ворота) и башни не
сверены и не поддержаны.

## Входы

`10c870(this = кэш, существо C, цель T, поиск PF, выход out)`; поле — `кэш+0x108`.

- Эффект `0x90` у C или `0x89` у T (через `T+4`) — список пуст.
- Досягаемость `r` = 6 с `long_weapon` (`1ef5e0`), иначе 2; если виртуальный `+0x3c` цели
  «да» — 0. У существа (подобъект `t_attackable_object` в `+0x9b4`, vtable VA `0x982450`) слот
  `+0x3c` — `f140`, всегда «нет».
- Части цели — список из слота `+0x28` (у существа `1f6960`); `T+8` — цель в башне.
- `a` — размер футпринта C (`C+8`, слот `+8`).

## Кандидаты

Для каждой части (угол `p` в 1/16 клетки, размер `s`): клетка-угол `p >> 4`, центр `p + 8s`;
предел `L = s + 1 + 2r`, наибольшее расстояние `D = 16r + 8 + 8a + 8s`. Если цель в башне —
`L` и `D` считаются по размеру башни (`get_obstacle(0x23)` в клетке центра части). Если C в
башне (`C+0x9bc`) — сначала запись для его собственной клетки с ценой 0 и расстоянием
`|центр части − центр C| + 8a − 8·размер башни`.

Затем `i, j` от `−a` до `L − 1`: клетка `(угол.x − r + i, угол.y − r + j)` в пределах поля, в
поиске достигнута (`0x01`) и не занята (`0x04`); `d` = центр части − центр футпринта C с этим
углом (`16x + 8a`); расстояние = `__ftol(sqrt(dx² + dy²) + 0.5)`; если ≤ `D` — запись в конец
вектора.

Запись (20 байт): угол `11ed40(d)` (`atan2(dy, −dx)·(−180)/π`, `__ftol`, `(360 − v) mod 360` —
та же формула, что в `51ede0`), x, y, расстояние, цена пути клетки.

## Порядок и прореживание

1. `std::sort` MSVC (до 16 записей — вставками `118620`, больше — `118190` и вставки) по
   (угол, x, y) — `10d020`. У одной части ключи различны, порядок однозначен.
2. Движение `M` (`C+0x98`, слот `+0x18`). Если записей ≥ 2: «ходов» = `(цена − 1) / M`
   (знаковое деление); наименьшее (начиная с 100), записи с большим — удаляются.
3. С последней записи к первой: `j = (i + 1) mod текущий размер`; если `i ≠ j` и разница
   углов (`11ed80`: `|a − b| mod 360`, больше 180 — дополнение) < 12.0 — удалить ту, чья
   дистанция **меньше** (при равенстве — `j`). Остаётся более дальняя позиция.

Следствие: для футпринта 1 без `long_weapon` позиции стоят в 2–3 клетках от цели, по одной
на угол; клетка вплотную выпадает, если на том же луче есть более дальняя.
